# Setup

## 1. Create the profile repository

The repository must be public and named exactly:

```text
Retr0Seven
```

Copy every file from this package into that repository and push to the default
branch.

## 2. Generate the live statistics

Open the repository on GitHub, then run:

```text
Actions → refresh stats → Run workflow
```

The workflow uses the repository's built-in `GITHUB_TOKEN`. No personal access
token or external statistics service is required.

For the workflow to commit generated files, repository Actions must have write
permission:

```text
Settings → Actions → General → Workflow permissions → Read and write permissions
```

## 3. Customize the hero

The animated quote and identity card are stored in:

```text
hero.svg
```

Edit its quote, title, location, or colors directly. It has no external image,
font, or script dependency.

## 4. Files generated by automation

The scheduled workflow owns these files:

```text
stats.svg
streak.svg
langs.svg
year.svg
hd-*.svg
```

Avoid regenerating them locally after the workflow is active, because local and
remote contribution windows can differ around UTC day boundaries.
